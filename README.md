# PBL3 Rescue Prototype

Phase 3A Foundation - Repository Skeleton

## Project Structure

```
PBL3-rescue/
├── backend/
│   ├── Org.Backend/          # C#/.NET backend with FastEndpoints
│   └── Org.Shared/           # Shared contracts (DTOs, enums)
├── frontend/
│   └── org-frontend/         # React + Vite + JavaScript frontend
├── docs/                     # Phase 3 documentation
└── PBL3-rescue.sln          # .NET solution file
```

## Technology Stack

**Backend:**
- C# / .NET 10
- FastEndpoints
- EF Core + PostgreSQL
- JWT Bearer Authentication
- SignalR (optional/future for notifications)

**Frontend:**
- React + Vite + JavaScript
- React Router v6+
- Axios for HTTP client
- Context API for state management
