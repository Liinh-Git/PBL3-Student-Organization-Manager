## Navigation Routes Requiring Guarding

- `NavMenu.razor` always includes organization menu routes: `/org/resources`, `/org/finance`, `/org/reports`.
- Message workspace icon always present and calls `IMessageService`-dependent flows.
- User workspace includes `/user/discover`; this route uses `DiscoverApiClient` (not supported in live).
