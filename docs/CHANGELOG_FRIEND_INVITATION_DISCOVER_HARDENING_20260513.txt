============================================================
3) MEMBER RECOMMENDATION -> LEADER REVIEW -> INVITATION FLOW
============================================================

Business flow implemented
- Normal member cannot directly invite member into org.
- Normal member can send recommendation request.
- Leader reviews recommendation in org requests page.
- On approve, system automatically creates real invitation for target user.
- Target user confirms in Discover -> My Organization Invitations.

Backend integration
- RequestService review logic handles recommendation marker:
  - if approved and request is ORG_INVITE_RECOMMEND,
    parse target user id from request payload and create invitation.
  - File: backend/Org.Backend/Features/Requests/Services/RequestService.cs

============================================================
4) DISCOVER PAGE HARDENING
============================================================

4.1 Partial failure resilience
- Discover no longer fully breaks when one optional section API fails.
- Uses per-section tolerant loading and shows partial warning.
- File: frontend/src/pages/user/UserDiscoverPage.jsx

4.2 Org invite filtering by existing membership
- For each friend, organization dropdown excludes orgs where that user is already a member.
- If no eligible org exists, invite disabled with "No eligible organization".
- File: frontend/src/pages/user/UserDiscoverPage.jsx

4.3 Invitation permission fallback
- If direct invitation fails due to permission,
  UI falls back to recommendation endpoint.
- Applied in Discover and Org Members pages.
- Files:
  - frontend/src/pages/user/UserDiscoverPage.jsx
  - frontend/src/pages/org/OrgMembersPage.jsx
