# BE_KNOWN_LIMITATIONS

## Supporting APIs
- Supporting APIs are build-fixed and baseline/read smoke-tested.
- Requests and Friends mutation flows were not fully exercised end-to-end in this pass to avoid unnecessary seed-data workflow mutations.

## Notifications
- No SignalR realtime notification delivery.
- REST polling model only.

## Excluded Modules
- No chat/messages module.
- No posts/comments module.
- No finance working module.
- No reports working module.
- No resources working module.
- No event ratings module.
- No event attendees working API.
- No digital assets upload API.
- No activity history feed API.

## Workflow Limitations
- Requests: simple review workflow only.
- Friends: no unfriend/block/search.
